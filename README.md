# DeadDrop

Защищённый **асинхронный** обмен сообщениями и криптовалютными транзакциями
через **недоверенного посредника** — любой носитель, способный хранить байты
(папка, облако/WebDAV, расшаренный документ). Носитель может читать, изменять,
удалять, повторять и блокировать данные; все гарантии обеспечивает криптография
поверх него.

Прикладной сценарий: частный бизнес, ведущий трансграничные крипторасчёты
(стейблкоины), которому нужен постоянный защищённый канал координации платежей —
в том числе в условиях ограничений. Магистерский дипломный проект.

## Возможности

- Сквозное шифрование (sealed-box) + подпись с привязкой к получателю
  (sign-then-encrypt): посредник не видит ни содержимого, ни отправителя.
- Анонимность получателя на носителе, защита от повтора и переадресации.
- Криптоагильность: алгоритмы за интерфейсом `Suite` (по умолчанию X25519 /
  HKDF-SHA-256 / XChaCha20-Poly1305 / Ed25519).
- Устойчивость к блокировке: мульти-носитель (зеркальная запись + слияние).
- Расширяемые типы нагрузки; готовый пример — **ко-подпись мультиподписи Safe
  (EVM)** для перевода стейблкоина.

## Архитектура

```
L3  message   — типы нагрузки (text, cryptotx/Safe) + реестр/сервис
L2  crypto    — личности, suite, sealed-box + подпись
L1  drop      — формат конверта, ящик (publish/poll/ack/GC)
L0  carrier   — носитель: Put/Get/List/Delete (fs · webdav · multi · mem)
```

## Использование

CLI (`abox`):

```sh
go build -o abox ./cmd/abox

abox keygen -out alice.json
abox contact -id alice.json > alice.contact      # публичная карточка
abox keygen -out bob.json
abox contact -id bob.json   > bob.contact

# обмен текстом через общий дроп
abox send -id alice.json -drop ./drop -to bob.contact -text "привет"
abox recv -id bob.json   -drop ./drop -once

# ко-подпись Safe 2-of-2 (перевод стейблкоина)
abox safe-propose -id alice.json -drop ./safedrop -to bob.contact \
  -wallet <hex> -chain 1 -safe 0x.. -token 0x.. -dest 0x.. -amount 1000000 -nonce 0
abox safe-cosign  -id bob.json   -drop ./safedrop -wallet <hex> -threshold 2 -once
```

TUI (`aboxtui`) — чат с живым приёмом и ко-подписью по `Ctrl-G`:

```sh
go build -o aboxtui ./cmd/aboxtui
aboxtui -id bob.json -drop ./drop -to alice.contact [-wallet <hex>]
```

Отпечатки личностей (`fingerprint`) сверяются по доверенному внеполосному каналу.

## Правовая оговорка

Система передаёт сообщения и транзакционные данные (артефакты подписи), но не
осуществляет расчётов, не хранит средства и не является обменником/платёжным
сервисом. Публикация транзакции в сеть выполняется отдельно (вне защищённого
канала). Исследовательский прототип на открытых алгоритмах.
